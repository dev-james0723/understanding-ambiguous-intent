# Changelog

## 0.4.0 - 2026-11-26 (experimental)

- Optional POSIX, read-only local Context Bridge, with explicit owner grants,
  bounded multilingual keyword search, provenance and keyed conflict reporting.
- Eight CLI and optional stdio MCP operations with fixed project scope.
- Synthetic adapter, security, distribution and actual MCP protocol tests.
- Preserve full-record search, identity and conflicts while returning bounded
  query-centered excerpts. Correct explicit expiry and malformed timestamp handling.
- Add a one-command synthetic demo and private configuration setup helper.
- Clarify cancellation, completed-task advice and lightweight task handoff.
- Add boundary pairs, multi-turn trajectories and an offline comparison report
  that binds judgments to exact response hashes.
- Add public failure-report template and worked examples.
- Publish the 72-response exploratory comparison: all three conditions tie at
  21/24 original-rubric passes, with explicit fixture and evidence limitations.
- Keep the portable runtime skill dependency-free. No cloud access,
  synchronization, automatic memory writes, telemetry or GitHub Actions.
- See [release verification](docs/verification.md). The original
  [candidate verification](docs/context-bridge-verification.md) is historical.


## 0.3.0 - 2026-11-24

First portable public experimental release, evolved from the owner's earlier
0.1 and 0.2 personal UAI pilots.

- Separate the requested deliverable from the decision to proceed or clarify.
- Add a clear-request fast path and context-first question policy.
- Preserve corrections, scope, exact identifiers, and applicable authorization.
- Treat multilingual input normally and handle transcription uncertainty explicitly.
- Separate optional memory capabilities from the dependency-free instruction core.
- Add English and Traditional Chinese documentation, reproducible local checks,
  isolated output-level evaluation fixtures, and an explicit evidence report.
- Remove personal aliases, machine paths, service dependencies, and private
  conversation content from the public package.

No universal performance or cross-host compatibility claim is made.
See [v0.3.0 verification](docs/verification-v0.3.0.md) for historical checks and limitations.
